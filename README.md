## Проекты

### ☕ Coffee Bakery — веб-приложение кофейни-пекарни

[Сайт](https://coffee-bakery-store.vercel.app/) · [Код](https://github.com/kristyjanzer/coffee-bakery-store)

Учебный fullstack-проект: каталог, корзина и оформление заказа.

- **Next.js + TypeScript**, типизированная модель данных
- **Zustand** для корзины с сохранением состояния между сессиями
- **Prisma** для работы с базой данных (товары, заказы)
- **E2E-тесты на Playwright**: полный сценарий «каталог → корзина → подтверждение заказа»
- **Юнит- и компонентные тесты** на Vitest + React Testing Library
- **CI на GitHub Actions**: линтинг, проверка типов, сборка
- Работа через pull request с защитой основной ветки, деплой на Vercel
