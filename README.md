## Проекты

### ☕ Coffee Bakery — веб-приложение кофейни-пекарни

[Сайт](https://coffee-bakery-store.vercel.app/) · [Код](https://github.com/kristyjanzer/coffee-bakery-store)

Учебный fullstack-проект: витрина для покупателей и закрытая админ-панель для управления магазином

`Next.js` `React` `TypeScript` `Prisma` `PostgreSQL` `Tailwind CSS` `Zustand` `NextAuth` `Zod` `Playwright` `Vitest`

- **Витрина:** каталог по категориям, карточка товара, корзина на Zustand с сохранением состояния, оформление заказа без регистрации
- **Админ-панель:** управление товарами, заказами, клиентами, отзывами и контентом сайта
- **Авторизация и роли:** NextAuth, разграничение доступа (администратор / менеджер заказов), защита админки на нескольких уровнях
- **Интеграции:** загрузка фото в Cloudinary, уведомления о новых заказах в Telegram, валидация данных на Zod
- **Тесты:** E2E-сценарий «каталог → корзина → заказ» на Playwright, компонентные и юнит-тесты на Vitest + React Testing Library
- **CI/CD:** GitHub Actions (линтинг, проверка типов, сборка, миграции БД), работа через pull request с защитой ветки, деплой на Vercel
